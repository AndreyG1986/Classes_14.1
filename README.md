#  Описание

В данном проекте реализована функция создания объектов по оределенному шаблону 
называемому классами.
Основной код для запуска находится в файле [main.py](src/main.py).

Логика работы реализована в файле [base_classes.py](src/base_classes.py)
class Product - создаёт шаблон с именем, описанием, ценой и кол-вом товаров
class Category - создаёт шаблон с именем, описанием, списком продуктов.
Также class Category содержит два метода: product_count для подсчёта элементов
в списке продуктов, и category_count для подсчёта категорий среди товаров.

Доработан метод ```__add__``` и прописан абстрактный метод BaseProduct,
который добавляет продукт в категорию таким образом,
чтобы не было возможности добавить вместо продукта или его наследников любой
другой объект.

Прописаны геттер ```@property``` price и сеттер ```@price.setter``` 
для проверки цены, чтобы не происходило операций с нулевой или отрицательной ценой.

Прописан ```@classmethod``` new_product проверяющий, что передаваемые данные
являются словарём и извлекающего эти данные из словаря.

В классе Сategory прописана функция add_product проверяющая с помощью метода 
```isinstance```, что передаваемый объект является наследником именно необходимого
вида продукта, добавляющяя этот вид продукта в список ```__products```, а также
ведущяя счёт ```category_count``` категорий.

Функция get_total_quantity  вычисляет общее количество товаров на складе
```product.quantity```, суммируя quantity всех продуктов в категории

Прописаны геттер и сеттер products и products_info для получения строки из приватного
атрибута ```__products```.

При необходимости с помощью функции ```get_products_list```, можем получить список
объектов продуктов из приватного атрибута ```__products```.

В данной работе добавлен файл [subclasses.py](src/subclasses.py), который
содежит два класса наследников класса Product: «Смартфон» (Smartphone) и 
«Трава газонная» (LawnGrass).

Класс «Смартфон» (Smartphone) расширен атрибутами: производительность (efficiency),
модель (model), объем встроенной памяти (memory), цвет (color).
Класс «Трава газонная» (LawnGrass) расширен атрибутами: страна-производитель
(country), срок прорастания (germination_period), цвет (color).

# Тестирование

## Установка через Poetry фреймворк Pytest и Code Coverage
1. Введите в терминале команду:
~~~
poetry add --group dev pytest
~~~

2. Запустите тесты в папке "tests" с помощью команды pytest.
Веедите в терминале команду:
~~~
pytest
~~~

3. В pytest для анализа покрытия кода надо поставить библиотеку 
pytest-cov:
Веедите в терминале команду:
~~~
poetry add --group dev pytest-cov
~~~

4. Чтобы запустить тесты с оценкой покрытия, можно воспользоваться следующими командами:
~~~
pytest --cov
~~~
 — при активированном виртуальном окружении.

5. В файле conftest.py находятся фикстуры - своего рода ячейки с данными, которые  
используются в файлах для тестов (файлах расположенных в папке tests с префиксом test_)

6. Чтобы сформировать отчёт о покрытии, можно ввести команду в терминале:
~~~
pytest --cov=src --cov-report=html
~~~

Отчет о покрытии в HTML-формате находится в папке htmlcov
 и храниться в файле с названием index.html.
Открывать данный отчёт необходимо с помощью браузера (Open In -> Browser).
